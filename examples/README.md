# Showcase portfolio

`showcase.ects-portfolio` is a ready-to-open, fictional example for demonstrating the portfolio maker. It includes a generated illustrated avatar, several clearly labeled demo projects, a sample credential and awards, and a generated project-report PDF. The sample credential and accomplishments are fictional; the PDF is marked as a demo and is not real student work. It contains no real name, recommendation, resume, or certificate.

In the app, choose **Open saved portfolio** and select `showcase.ects-portfolio`, or choose **Load fictional demo** on the start page. The app will ask before replacing the portfolio currently open. Do not present the example as a real student's record; replace the demo entries before sharing it as a personal portfolio.

To rebuild the archive from its readable JSON and generated assets, run:

```sh
python examples/build_showcase.py
```
